# Karten
*A JavaFX-based, offline flashcard study application with interactive minigames, aimed primarily at elementary-aged learners.*

Hello, my name is Ivan, and this is Karten, a work-in-progress app for my IB MYP Personal Project. Karten sounds like just another studying tool, but it differs in many important ways:

- **Offline-first learning** to remove the dangers and intrigue of the Internet world, which serve to distract from learning.
- **Child-focused UI and UX** that creates an interesting yet calm educational space for maximum focus.
- **Local data persistence** to forget the troubles of an Internet connection and focus on the human ones.
- **Minigame-based studying** to make learning fun, backed by child neurological research.

## Project State
This project is in early development. Many features are incomplete, and the product is not meant to be used at this point. The repository and this document will also be expanded in the near future.

Stay tuned for more.
